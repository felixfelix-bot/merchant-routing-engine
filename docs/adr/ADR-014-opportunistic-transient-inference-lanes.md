# ADR-014: Opportunistic Transient Inference Lanes

- **Status:** Accepted (operator-ratified 2026-09-06, this thread)
- **Context:** The 2026-09-06 OpenInference pass rejected a lane offering the cheapest DS-V4-Flash pricing ever measured (eff $0.0093/M, 2.4× under DeepInfra) on longevity/viability grounds. Operator directive (2026-09-06): *"I'm looking to get high quality tokens for as cheap as possible — maximize bang for the buck at all times. We don't need to make long-term commitments. We can pivot to other providers when the opportunity dries up."* The fleet runs 2.95B tok/30d; 76% rides flat $0 subscription lanes (~1.1B tok/mo combined ollama cloud), metered spend ~$25/wk. Consultant EV analysis: cash savings ≈ break-even (~$156/yr vs ~$164/yr cost), but insurance value dominates — if flat lanes die (grandfathered pricing cancelled), re-homing 1,100 M/mo costs $105–166/mo on incumbent metered lanes vs ~$10/mo on a pre-gated cheap transient lane. Quota-outage weeks (z.ai keys dry, Sep 5 precedent) also benefit.
- **Decision:** Adopt **transient lanes as first-class routing citizens**. A lane is a disposable opportunity, not infrastructure:
  1. **Longevity is explicitly NOT a selection criterion.** Expected life ≥ 1 week qualifies. Below-cost / loss-leader / teaser pricing is a *feature to exploit until it dies*, not a red flag — provided exposure is capped (rule 4). Future evaluations MUST NOT re-litigate provider durability; the 2026-09-06 OpenInference longevity rejection is the canonical failure this rule kills.
  2. **Selection = cheapest verified effective price that passes the quality gate.** Price verified live from the provider's own catalog (`/v1/models` authless first; OR endpoints API as cross-check). Quality gate BEFORE real traffic: (a) garbage circuit-breaker armed (already live, per-(provider,model)); (b) canary pass — ~20 fixed prompts vs reference lane, ≥90% sane, no repetition blowup (≤3× prompt length); cost ≤$1/lane. Extend `quality_floor.py` as the hook; a lane without a passing gate never enters candidacy.
  3. **Fast-path onboarding (5 steps, ≤30 min, ≤1 proxy restart):** env key + `EXTERNAL_PROVIDERS` → `PROVIDER_MODELS` + `_PROVIDER_MODEL_NAMES` translation → `_SEED_RATES` (catalog price) → **mandatory** `_extract_cost` rate branch (else NULL cost_usd = invisible burn) → daily-spend cap guard for any lane holding >$20 (copy `_routstrd_daily_cap_tripped` pattern, ~15 lines, fail-open). Balance bridge, optimizer registration, and ratification review are DEFERRED for transient lanes (consultant-verified file:line: seed fallback covers routing; Kalman is in-memory per-provider, self-cleaning on removal).
  4. **Exposure cap: deposit ≤$50/lane, smallest tier, auto-top-up — never park balance.** No-refund / sole-discretion-termination ToS is acceptable at this exposure, not a disqualifier. Pay via virtual CC / Stripe. Internal workloads only (resale bans irrelevant — we don't resell these lanes; routstr NEVER routes through transient lanes).
  5. **Privacy carve-out:** client-privacy-sensitive workloads (sitarani class) NEVER route to transient lanes regardless of price — unproven data policies.
  6. **Concentration + kill rules:** unproven lanes (<2 wk live) carry ≤20% of metered burn. Kill same-day on: effective price > incumbent + 20%, canary regression, or provider death (402/401 — health tracking already benches it automatically; 402 retries every 300s so the daily-cap guard is the real stop). Keep ≥1 proven transient lane LIVE at all times (regime-c rehearsal: a flat-lane-death event becomes a re-price, not a scramble).
  7. **Bookkeeping:** registry entry in `providers.yaml` with `status: transient`, verified prices, deposit ceiling. Provider-hunt fence updated when a find converts to a lane (watch → transient-candidate).
- **Consequences:**
  - (+) Daily provider-hunt converts directly into cheap tokens instead of parking finds in reports; marginal cost per lane ≈ 30 min agent time + $5 probes + $20–50 refundable-ish deposit.
  - (+) Flat-lane-death scenario drops from $105–166/mo to ~$10/mo; quota-outage weeks get cheaper failover.
  - (+) Lane death is a non-event: pre-flight failures fail over to next candidate mid-loop (user sees a retried request, not an error); no persistent routing poison (health/CB state per-provider, TTL'd).
  - (−) Mid-stream provider death is terminal for that response (`_response_started` guard) — rare, bounded by canary-gated onboarding.
  - (−) Cheap-garbage risk requires the quality gate to be real, not aspirational — the NW glm-5.3 token-spam incident (77k garbage tokens, HTTP 200) is the standing example; gate-before-traffic is non-negotiable.
  - (−) Agent-time overhead ~4 lanes/yr at ~1h each; below our task bar only because the hunt cron already runs daily.
- **First candidates:** OpenInference base-Flash (eff $0.0093/M — upgrade from WATCH to TRANSIENT-CANDIDATE under this ADR, gates apply: canary + $20–50 deposit), Baidu-0731-via-OR ($0.05/$0.10/$0.01), DigitalOcean base-Flash via OR ($0.068/$0.168).
